## Added

- **Notification channels**: `notify.channels`, `notify.channel` (importance/sound/vibration; channel attributes are immutable once created)
- **Progress notifications**: `progress {value,max,indeterminate}`
- **Live Update (Android 16)**: `progress.live=true` → `Notification.ProgressStyle` + promotion request, shows a progress capsule in the status bar. Requires `appops set lll.bridge.termux POST_PROMOTED_NOTIFICATIONS allow`, otherwise `can_promote=false` (falls back to a normal notification).
- **Action buttons**: `actions[{label,json}]` — tapping executes any bridge command
- **Notification listener** (`BridgeNotifListener`): caches the last 80 notifications with package/title/text/progress/actions. Grant without dialogs: `cmd notification allow_listener lll.bridge.termux/lll.bridge.termux.BridgeNotifListener`. Commands: `notif.status`, `notif.recent`, `notif.clear`, `notif.dismiss`, `notif.perm`
- **Material You palette**: `theme.colors` → full accent1–3 / neutral1–2 scales + wallpaper dominant color
- **Window blur**: `theme.blur` capability probe; overlay `blur:30` → `FLAG_BLUR_BEHIND` + `blurBehindRadius` (verified registered on device)
- **App launching**: `app.list` (235 launchable apps), `app.launch PKG [URI]`, `app.info`, `app.settings` (OEM auto-start toggles can only be opened manually from the app info page)
- **Home screen widget**: battery/port/time, `widget.info` / `widget.update` / `widget.pin`
- **Overlay gestures**: tap / double-tap / triple-tap / long-press (500 ms) / 4-direction swipe, returned via the event queue

## Changed

- **Coordinates unified to dp** — v1.1 mixed dp (x/y) with px (w/h), which broke cross-device consistency.
- Introduced an `R` class (aapt2 link before javac), enabling layout/resource references.

## Known limitations

- Live Update requires the appop grant; some ROMs lack the capability.
- Blur requires cross-window blur support (verified enabled on the test device).
- The widget must be added manually (`widget.pin` invokes the pin flow).
- The notification listener needs the special "notification access" grant.
