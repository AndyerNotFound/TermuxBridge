## Added

- **Custom overlay windows** (`tbridge-overlay`): describe layouts in JSON; the app builds Views and overlays them on screen, click events are returned to Termux.
  Node types: `col`, `row`, `text`, `button`, `input`, `progress`, `divider`, `spacer`; style props `bg`, `radius`, `pad`, `m`, `size`, `color`, `align`, `weight`, `alpha`.

  ```bash
  tbridge-overlay demo
  tbridge-overlay show card.json
  tbridge-overlay bounds      # real screen coordinates
  tbridge-overlay events      # click events (draining)
  tbridge-overlay values ID   # input field contents
  tbridge-overlay hide all
  ```
- **Battery optimization exemption** (`tbridge-power status|request|settings`), or via Shizuku: `cmd deviceidle whitelist +lll.bridge.termux`.

## Upgrade note

Reinstalling over an existing build disables the accessibility service; re-enable with:

```bash
rish -c "settings put secure enabled_accessibility_services lll.bridge.termux/lll.bridge.termux.BridgeA11yService; settings put secure accessibility_enabled 1"
```
