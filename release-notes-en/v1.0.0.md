Initial release of TermuxBridge — a bridge between Termux and Android system capabilities that pure CLI access cannot reach, exposed over a local TCP JSON protocol (127.0.0.1:8021).

## Downloads

| Asset | Purpose |
|---|---|
| `TermuxBridge.apk` | Android app (41 KB, self-signed, not distributed via stores) |
| `tbridge_1.0.0_all.deb` | Termux CLI package (31 commands, Termux:API style, no `termux-*` name collisions) |
| `SHA256SUMS` | Checksums |

## Features

- **Messaging**: toast, notifications, vibration, beep, TTS
- **Clipboard**: read/write via a transparent focus-capture activity (Android 10+ restriction)
- **Status**: battery, network, screen brightness, volume, sensor list/single sample, location
- **Hardware**: torch, brightness, volume
- **Intents**: share text/files, open URLs, dial, send SMS
- **Screen**: accessibility screenshot (no prompt), MediaProjection fallback, tap/swipe injection, UI tree dump
- **Voice**: audio recording (WAV), system speech recognition
- **Misc**: 17 independently toggleable modules, optional token auth, broadcast fallback channel, boot autostart

## Install

```bash
# 1. App
adb install TermuxBridge.apk
# or with Termux + Shizuku:
cat TermuxBridge.apk | ~/Shizuku/rish -c "pm install -r -S $(stat -c%s TermuxBridge.apk)"

# 2. CLI
pkg install jq netcat-openbsd
dpkg -i tbridge_1.0.0_all.deb

# 3. Start the service
tbridge-service start
```

Accessibility features (screenshot / touch injection / UI tree) require enabling TermuxBridge once under Settings → Accessibility.

## Notes

- Verified on Android 16 (SDK 36), arm64; all commands tested on device.
- Not implemented: notification listener, overlay windows, VPN service, USB exclusive access.
